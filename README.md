# rand-hash

Generate random hash values for LLMs as random seed.

## Usage

Download the executable file and run it, and the random hash values will be automatically copied into your clipboard. Just paste them into your prompt.

**Example Content:**

```
MD5: ...
SHA1: ...
SHA224: ...
SHA256: ...
```

## Build & Run

```bash
cargo build
cargo run
```
